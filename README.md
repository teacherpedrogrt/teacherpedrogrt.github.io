# Teacher Pedro · Site da bio

Página única do link da bio do Instagram [@teacherpedrogrt](https://instagram.com/teacherpedrogrt): quem sou, método, como funciona, modalidades, valores, horários e contato.

- `index.html`: o site (publicado pelo GitHub Pages).
- `skill/`: a skill que o Claude usa para criar, alterar e publicar as páginas. Os dados oficiais ficam em `skill/references/conteudo.md` e a lista de páginas em `references/paginas.md`.
- Páginas novas ficam em pastas próprias (ex.: `black-friday/index.html` → `https://teacherpedrogrt.github.io/black-friday/`).

Inglês é treino, não matéria.
